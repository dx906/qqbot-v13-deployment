# V1.3 术语分级表

> 用途：把《大肥鱼系统》v2.0 的概念词与**本项目真实实现**对齐，标明每个术语处在哪一级。
> 防止「文档说一套、代码是另一套」。更新时间：2026-10-27 03:15
>
> 分级定义：
> - **A 已实现**：代码里能跑，有实测证据
> - **B 部分实现**：有对应机制但不完整 / 参数未标定
> - **C 未实现**：只有文档设计，代码里没有
> - **D 已证伪**：实测数据不支持，已明确不用

## 5. 术语对照：文档词 → 代码词

## 一句话

> 本项目真实落地的是**「L3 事实 + 遗忘曲线 + 两档注入 + 写入门」**这套工程机制；
> 文档里的「量子化决策 / 64 卦编码 / 六维驱力」仍是设计稿，**不要在对外表述里说成已实现**。
> 唯一被数据推翻的文档建议是「领先度 ≥0.15」，已标记 D 级。
