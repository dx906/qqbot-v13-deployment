## 2. 启动与停止

### 启动（幂等，可重复点）

```powershell
wscript "D:\AI\QQBot-v13\_setup\start-v13-stack.vbs"
```

- Windows 登录后**自动执行**（快捷方式 `Startup\V13-Stack.vbs.lnk`）
- 桌面快捷方式 `V1.3.lnk` 手动启动
- 服务已在跑时不会起第二个进程
- 日志：`D:\AI\QQBot-v13\logs\stack.log`

### 停止

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\AI\QQBot-v13\_setup\stop-v13-stack.ps1"
```

只停 6381/6382/1936/8127/8329/5199 且校验命令行归属；`8326`、`8331`、`3210`、`8788` 不受影响。

### 为什么必须用 VBScript

2026-10-27 03:20 曾出现 embed / OV / persona 三个服务同时消失，`persona-svc-v11.log` 末尾是一个 `^C`——它们是从 bash/pwsh 会话里启动的，会话销毁时整个控制台组收到 Ctrl+C。

`wscript.exe` 没有控制台，`Run(..., 0, ...)` 使每个子进程获得隐藏窗口，整条链不再依附任何 shell。这是落地后的固定启动方式，**不要再用 bash 或 pwsh 直接起这些服务**。
